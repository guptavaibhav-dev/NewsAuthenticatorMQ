### Data flow

1. `POST /api/runs` with `{text, url}` → Layer 1 ingest → `awaiting_decision` (`main.py` lines 109–126; orchestrator after each layer except 7).
2. Journalist Proceed → Layer 2 → 3 → 4 → 5.
3. Layer 6: dashboard records `human_decision`; system will not auto-commit (`orchestrator.py` lines 86–101).
4. Confirm immediately runs Layer 7 (`main.py` lines 274–276; documentation diagram “Starts immediately after Confirm”).
5. Envelope persisted as `backend/.runs/{run_id}.json` (`pipeline/store.py` lines 10, 49–58). Gitignored (`.gitignore` line 26).
6. SSE `/api/runs/{id}/events` streams `trace` (`main.py` lines 137–159).
7. Snapshots per layer enable Re-run (`orchestrator.py` `take_snapshot` / `restore_snapshot`).

**Hard pipeline rule, repeated in many files:** a failed, blocked, paywalled, skipped, or empty search is a **coverage gap, never a signal of falsity** (e.g. `envelope.py` lines 45–46; `retrieval/README.md` lines 10–11; workspace rule `keep-diagrams-in-sync.mdc` “Thesis framing”).
